# Task Packet

## Objective

Provide the least-privilege, reviewable OpenCode permission profile required to
run B0 headlessly without using broad automatic approval.

## Context

Read the accepted controlled-orchestration architecture, B0 task card, and the
OpenCode bootstrap incident. The prior session could read its task but stopped
on tool-permission prompts.

## Constraints

Do not launch OpenCode, read credentials, access session logs, create an
external runtime config, modify a worktree, commit, push, or use `--auto`.
This task creates a versioned profile only; the operator separately approves
any future runtime invocation.

## Implementation Notes

Use OpenCode's documented v1 `permission` rules. Start from deny/ask and add
only exact B0 paths and commands. Explicit denials must cover network-capable
tools, external directories, task spawning, commit, push, package installation,
and arbitrary shell commands.

## Validation Steps

Parse the JSON with the standard library, inspect all allow/deny entries, run
coordination validation, and run `git diff --check`.

## Escalation Rules

Stop and open an incident if a broader permission, a secret, a runtime launch,
or a source/worktree change is needed.
