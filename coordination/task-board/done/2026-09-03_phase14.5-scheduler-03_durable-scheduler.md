# Task Packet

## Objective

Implement the Phase C durable scheduler contract after Phase B admission is
accepted.

## Context

Read `docs/architecture/controlled-orchestration-architecture.md`,
`docs/operations/phase14.5-controlled-orchestration-task-map.md`, the accepted
Phase B task, review, and delivery evidence, and existing coordination scripts.

## Constraints

Do not launch a runtime, read credentials, create a connector grant, merge,
push, or make a task-card transition outside the scheduler's validated writer
path. Use only local deterministic fixtures and a fake clock in tests.

## Implementation Notes

Keep the event feed a rebuildable projection, not a second lifecycle state
machine. Use an immutable envelope with message ID, idempotency key, task/run
identity, attempt, lease epoch, expiry, and safe reference fields.

## Validation Steps

Run focused scheduler tests for restart, duplicate delivery, stale messages,
and revision conflicts; run coordination validation and `git diff --check`.

## Escalation Rules

Open an incident and stop if the work needs an actual runtime, credentials,
network transport, or a task lifecycle write outside the scheduler contract.
