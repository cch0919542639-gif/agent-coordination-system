# Task Packet

## Objective

Implement the minimum separately reviewable effectful adapter required before
Phase H connector provision. It is a local process boundary, not a live pilot.

## Context

Read the Phase H pilot protocol, the supervised launcher contract, Phase B
admission contract, and Phase G operator-surface contract. Reuse their exact
safe identifiers and no-leak conventions rather than adding a second manifest
or grant system.

## Constraints

This task is authorized to implement and test the adapter only. It must not
start an actual connector, contact a network, access credentials, create a
Git worktree, merge, push, or clean up worktrees. A deny-network value alone
is insufficient enforcement evidence.

## Implementation Notes

Use the standard library and the existing injected-factory pattern. Keep the
attestation as a narrow caller-supplied record; platform-specific enforcement
setup belongs to the later provisioning task. Do not add a CLI, persistence,
environment lookup, fallback runtime, or background service.

## Token And Resource Impact

No runtime is started. Unit tests use only fake factories; resource impact is
bounded to normal test execution. The caller can disable the adapter by
withholding the exact approval or attestation.

## Validation Steps

Run the focused adapter tests, the affected Phase B.1--H fixture suite,
`scripts/orchestrate.py validate`, and `git diff --check`.

## Escalation Rules

Stop and write an incident if reliable restricted-write, process-identity, or
network-deny evidence cannot be represented without a platform action. Do not
weaken the acceptance criteria or substitute a mock for that evidence.
