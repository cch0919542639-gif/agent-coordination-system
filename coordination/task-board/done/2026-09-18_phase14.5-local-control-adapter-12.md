# Task Packet

## Objective

Implement the reviewed L1 local-control boundary required before a Phase H L1
pilot can be eligible for a separately approved process start.

## Context

Read the L1/L2 rebaseline, the accepted L2 adapter/provisioner contracts, and
the Phase H pilot protocol. Existing L2 components are not a starting point for
an L1 launch path and must remain unchanged.

## Constraints

L1 is `best_effort` local controlled collaboration, not a security sandbox.
It must not claim enforced restricted writes, independent OS process identity,
or denied network egress. A real runtime start remains separately one-shot
approved; this task uses fake injected process boundaries only.

## Implementation Notes

Keep the boundary small and deterministic. Accept only exact safe records and
return privacy-bounded, `best_effort` evidence. Do not add credentials,
networking, a CLI, persistence, or a runtime factory that starts a real process.

## Validation Steps

Run the focused L1 adapter/provisioner tests, the affected Phase B.1--H fixture
suite, `scripts/orchestrate.py validate`, and `git diff --check`.

## Escalation Rules

Stop and file an incident if the requested boundary requires credentials,
network activation, a real connector/runtime, Git worktree mutation, merge,
push, destructive cleanup, or an L2 enforcement claim.
