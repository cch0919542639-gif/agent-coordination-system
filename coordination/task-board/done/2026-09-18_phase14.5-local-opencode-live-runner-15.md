# Task Packet

## Objective

Implement the smallest reviewed live-process boundary required for a future
one-shot Phase H OpenCode pilot. It must be callable only after the already
accepted approval and scrubbed-environment boundaries have accepted an exact
request.

## Context

This workstation resolves `opencode` through its local PowerShell wrapper,
not a directly callable `opencode.exe`. The operator has authorized one exact
future pilot to let that local process use its existing provider login and
contact its configured model service. This packet adds no launch authority of
its own and does not exercise that authorization.

## Constraints

The runner is an L1 `best_effort` control, never a sandbox or a claim of host
network/process/filesystem enforcement. It may use `subprocess.Popen` only in
the runner's production seam; tests must inject a fake. A fixed PowerShell
wrapper invocation remains `shell=False` and may not inherit the host
environment. The wrapper reference is a recorded, pinned launcher input, not
an arbitrary command, URL, profile, or lookup result.

## Implementation Notes

Reuse existing validation and executor helpers rather than duplicating their
schemas. Use only the Python standard library. Keep the live runner focused:
no CLI, background service, retries, output capture, credential/configuration
discovery, filesystem persistence, worktree provisioning, or new dependency.
If a required launcher datum cannot be represented without an absolute path
or its safety cannot be verified, stop and write an incident rather than
loosening the contract.

## Validation Steps

Run the focused runner tests plus affected L1/Phase B.1--H tests with an
isolated pytest base temp, `scripts/orchestrate.py validate`, `py_compile`,
and `git diff --check`.

## Escalation Rules

Stop and file an incident for any need to execute OpenCode, access a provider
credential/configuration/environment value, accept a dynamic shell command or
launcher, log child output, add a retry/fallback, create worktrees, or broaden
the one-shot provider/network exception.
