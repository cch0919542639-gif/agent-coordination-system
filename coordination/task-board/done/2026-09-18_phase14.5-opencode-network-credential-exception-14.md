# Task Packet

## Objective

Implement the operator-authorized, one-shot L1 exception that lets OpenCode
use its existing local provider configuration to contact its configured model
service during a future exact Phase H pilot.

## Context

The operator explicitly authorized existing-provider credential use and model
service network access for this one-shot pilot only. This task prepares a
reviewed boundary; it does not launch OpenCode or test a credential.

## Constraints

The exception is task/run-bound, enabled only within its recorded window, and
must be default-deny. It cannot authorize arbitrary endpoints, a credential
export, transcript/output capture, merge, push, destructive cleanup, Git
worktree mutation, or repeat run. L1 remains best-effort; it must not claim
network denial or sandbox enforcement outside this exception.

## Implementation Notes

Use exact schemas and caller-supplied allowlisted environment keys. Keep
values opaque and out of all result/evidence records. Preserve the existing
injected fake-spawn design and do not add dependencies, a CLI, persistence, or
background service.

## Token And Resource Impact

No network call occurs in tests. The future run is one-shot and bounded; the
exception expires automatically and can be disabled by withholding approval.

## Validation Steps

Run focused exception/L1 tests, affected Phase B.1--H suite,
`scripts/orchestrate.py validate`, and `git diff --check`.

## Escalation Rules

Stop and file an incident if a requirement needs a literal credential, an
unbounded endpoint/provider scope, an inherited arbitrary environment, a real
test call, or any retry/fallback behavior.
