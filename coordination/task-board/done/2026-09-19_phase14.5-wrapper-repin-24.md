# Task Packet

## Objective

Recover the unavailable wrapper-provenance prerequisite without weakening the
launch boundary. Create and pin one reviewed project-owned wrapper, then make
the pin independently reviewable before any later pilot preflight.

## Context

Task 23 failed before admission: no local wrapper path matched the historical
opaque path digest. No approval ID, launch ID, binding token, OpenCode child,
credential, provider configuration, or network request was used. The operator
authorized a separately scoped re-pin plus independent review.

## Constraints

Use the smallest reusable boundary: one static wrapper and content digest,
not a discovery service, configuration store, or fallback launcher. The raw
absolute wrapper path remains an input-only value and must never be recorded
or returned. The task is fake-Popen-only and must not execute PowerShell,
OpenCode, any network action, or any credential/provider lookup.

## Implementation Notes

Keep the existing launcher mapping shape where possible. Use stdlib hashing
and the existing injected Popen seam. The wrapper must not add argument
rewriting, environment discovery, logging, output capture, retries, or
fallback behavior. A future pilot still requires a clean fresh preflight and
the already recorded operator authority; this task grants neither.

## Validation Steps

Run the focused live-runner and dependent provision/executor/launcher tests
with isolated basetemp, plus PowerShell syntax validation only if it can be
performed without executing the wrapper. Run `py_compile`, coordination
validation, diff check, and a static scan for forbidden APIs.

## Escalation Rules

Stop and record an incident for any need to inspect provider configuration,
credentials, child output, or to run the wrapper. Do not alter Task 23's
blocked run, approval, or tokens.
