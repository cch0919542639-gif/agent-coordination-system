# Task Packet

## Objective

Produce and validate one reviewed, non-secret structured invocation projection
for the accepted Python-only live runner, resolving Task 28's capability
mismatch without adding a second launch path.

## Context

Task 28 correctly stopped before admission because its operator packet had no
current callable projection for the runner's structured request, approval,
record, launcher, and opaque context inputs. The operator requested this
small artifact task. Task 27 supplies six current clean bindings; Task 25
supplies the accepted runtime binding. Neither grants a pilot launch.

## Constraints

Implement only the smallest pure builder/validator needed to freeze safe
non-secret fields. The builder must not read host configuration, discover a
runtime, call the runner, or generate immediate-boundary identifiers. Do not
serialize sensitive values or raw locations. No CLI or external side effect is
permitted.

## Implementation Notes

Read existing executor and runner interfaces before editing, then reuse their
data shapes and validation helpers. Prefer one pure module and focused tests.
The result must be sufficient for a later, separately authorized operator
packet to supply opaque immediate-boundary inputs without source inspection or
guessed mapping.

## Validation Steps

Run focused projection, executor, and live-runner tests with isolated basetemp,
then `py_compile`, coordination validation, and `git diff --check`. Include
tests proving malformed/secret-bearing/cross-wired projection reaches no spawn
seam.

## Escalation Rules

Stop and create a redacted incident for any required sensitive value, host
configuration access, runtime invocation, source-copying into evidence, or
scope expansion. Do not revive or launch Task 28.
