# Task Packet

## Objective

Repair the current six-worktree preflight's ownership-guard handling without
weakening its fail-closed binding verification.

## Context

Task 30 stopped before admission because ordinary Git reads received the local
ownership guard for all six otherwise existing detached bindings. Task 27's
accepted recovery used a scoped, one-process safe-directory setting; this
task makes that same limited read pattern explicit and testable.

## Constraints

Resolve each relative reference below the caller-declared root before Git is
called. Scope `safe.directory` to that exact resolved target on that command
only. Do not persist configuration or return a target path, command, or Git
output in results.

## Implementation Notes

Use the standard library and one helper module with injected command execution
for focused tests. Do not add a CLI, a second preflight path, or any launch
capability.

## Token And Resource Impact (If Applicable)

Not applicable. The helper performs bounded local Git reads only and has no
agent, runtime, provider, or network effect.

## Validation Steps

Run the focused helper tests, coordination validation, and `git diff --check`.
Submit the result for independent review; Task 30 remains blocked throughout.

## Escalation Rules

Stop if a safe-directory scope cannot be limited to an exact resolved binding,
or if a fix requires persistent configuration or a runtime action.
