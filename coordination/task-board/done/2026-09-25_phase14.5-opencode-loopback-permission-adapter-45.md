# Task Packet

## Objective

Prepare the injected loopback adapter for the accepted Task 44 controller.
It is a deterministic preparation task only.

## Constraints

## Context

Task 44 provides the injected one-time permission core. This task supplies
only its injected loopback adapter, not a live transport or launch authority.

## Boundary Constraints

Do not open a socket, start OpenCode, or send HTTP. The injected retrieval and
reply callables stand in for a future reviewed live transport. The adapter must
make a raw resource digest in memory, never return resources, and accept only
the literal `http://127.0.0.1:<port>` origin.

## Implementation Notes

Reuse Task 44's `reply_once` rather than duplicating its binding or one-shot
checks. Any future server launcher remains a separately reviewed task.

## Validation Steps

Run the focused tests and coordination validation, then submit for independent
review.

## Escalation Rules

Stop if the server API cannot supply a single permission request, if raw
resources would need to be persisted, or if a real server/runtime/credential
operation is required.
