# Task Packet

## Objective

Implement the pure/injected OpenCode API mapping and bounded task payload builder
needed to send the actual assigned task instead of the literal message
`restricted`.

## Context

Task 46 observed OpenCode 1.18.32's public API. Its permission request fields are
`id`, `sessionID`, `permission`, `patterns`, `metadata`, `always`, and optional
`tool` (`messageID`, `callID`). The modern reply route is
`POST /permission/{requestID}/reply` with `reply` and optional `message`; the
reply enum is `once`, `always`, `reject`. The deprecated
`/session/{sessionID}/permissions/{permissionID}` route takes `response` and
does not declare `remember`.

## Implementation Notes

Keep the transport injected. Use the normalized permission identity and a
canonical digest of the permission name and patterns; never return raw metadata
or patterns. Build prompts from the exact allowlisted task fields only.

## Constraints

This packet is transport-injected preparation only. Do not contact the API,
start OpenCode, send a prompt, or issue a permission reply. Reject rather than
guess on any API shape drift. Do not persist raw permission metadata or
patterns.

## Validation Steps

Run the new focused test module and coordination validation. Submit artifacts
for independent review before adding a live transport caller.

## Escalation Rules

Stop on schema disagreement with version 1.18.32, need for an unbounded task
payload, or need to inspect credentials/configuration.
