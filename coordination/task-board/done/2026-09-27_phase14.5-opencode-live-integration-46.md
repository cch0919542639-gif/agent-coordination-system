# Task Packet

## Objective

Resolve the installed API compatibility gap between the accepted transport-free
Task 44/45 adapters and OpenCode 1.18.32. This is a diagnostic continuation of
the user's authorized local OpenCode recovery, not a retry of Task 43.

## Context

CLI version and serve help now exit zero after package postinstall repair.
`run restricted` supplies a message; it is not a restriction switch. Native
Desktop automation has also been observed working. Neither proves pilot success.

## Constraints

One explicit schema-probe invocation, one server spawn, at most 45 seconds.
Use a fresh in-memory local server password (not provider credentials), no
redirects/proxies, GET only `/global/health` and `/doc`, no sessions/config/auth
endpoints, no raw process output. An unsuccessful probe is terminal for this
attempt and must not be retried automatically. Independent review precedes run.

## Implementation Notes

Use Python stdlib; preserve Task 44/45 contracts until installed API evidence
shows what must change. Existing global settings are not modified. This is L1
best-effort; `--pure` disables plugins, not filesystem/network enforcement.

## Validation Steps

Run focused tests; independently review probe and scope; execute once only if
accepted. Record safe schema summary and teardown result, then review evidence.

## Escalation Rules

Stop on digest mismatch, unexpected API shapes, teardown failure, or any need
to send a model prompt/change credentials. Do not promote Phase H to complete.
