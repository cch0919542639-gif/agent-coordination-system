## Objective

Make the lead agent the only lifecycle reviewer and let it advance each clear,
evidence-backed delivery immediately. Pause only when the lead agent needs a
human decision or identifies risk.

## Context

Task 54 automatically submits controller-observed delivery evidence to review.
The user's updated policy replaces mandatory human acceptance with lead-agent
triage. The first local implementation introduced a triage CLI but had not been
validated and still deferred safe decisions whenever another unrelated review
was pending.

## Constraints

Keep review and dispatch evidence in the existing coordination folders. Preserve
dependency gates and the rule that assignment does not launch a worker. Existing
cross-machine workers are out of scope for this local continuation.

## Implementation Notes

Require controller triage before lifecycle-changing review decisions. Make a
pause fail closed. Remove unrelated-review-queue barriers from safe
continuations, while retaining the existing at-most-one dependency-ready task
assignment after acceptance. Align validation with the current review template.

## Validation Steps

Run focused fake-only controller-review/redispatch tests, module compilation,
coordination validation, and `git diff --check`. Do not start OpenCode or call a
live API.

## Escalation Rules

If implementation would require enabling a recurring external automation,
launching a task-bound worker, changing credentials/permissions, or publishing
to GitHub, stop with the concrete artifact ready and request the necessary
authorization.
