# Task Packet

## Objective

Implement the first no-launch control-plane primitive required for six-agent
coordination: connector-grant validation and deterministic admission planning.

## Context

Read `docs/architecture/controlled-orchestration-architecture.md`, the root
context kit, `scripts/worker_poller.py`, `scripts/project_registry.py`, and
the Phase A task/delivery/review evidence. Munder Difflin is a design reference
only: reuse its single-writer and atomic-file ownership lessons, not its UI,
auto-installer, secret handling, or unverified OpenCode bridge.

## Constraints

- Do not start a runtime, write a handoff, modify lifecycle state, invoke Git,
  use network services, or read credentials.
- Treat grants as local runtime state; keep only opaque credential references.

## Implementation Notes

Reuse the existing safe registry and JSON patterns. Plan mode must be pure and
testable with a fake clock.

## Validation Steps

Run focused tests, coordination validation, safe JSON inspection, and
`git diff --check`.

## Escalation Rules

Open an incident and stop if implementation needs a real connector, credential,
runtime launch, task-card mutation, or a new global resource.
