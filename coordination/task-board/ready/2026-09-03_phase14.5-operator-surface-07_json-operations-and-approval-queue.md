# Task Packet

## Objective

Implement Phase G's JSON-first operator projections and approval queue after
the accepted evidence/review queue contract.

## Context

Read accepted Phase F evidence and the architecture's “Operator Surface” and
critical-action rules.

## Constraints

Do not add a dashboard, web API, connector launch path, credential store,
merge/push operation, or destructive cleanup command.

## Implementation Notes

This is an observability and decision interface. Its output must remain a safe
projection; an absent approval is a denial, never an interactive fallback.

## Validation Steps

Run JSON-schema/field allowlist tests and negative tests for critical-action
execution; run coordination validation and `git diff --check`.

## Escalation Rules

Stop and open an incident if a UI, network API, runtime launch, secret, or
automatic approval becomes necessary.
