# Task Packet

## Objective

Add the minimal evidence needed to distinguish a real constrained child start
from a pre-spawn or Popen failure in the next user-authorized pilot.

## Context

The first live pilot safely terminated all bindings but did not prove that all
children reached a started state. This task adds evidence only; it performs no
live launch.

## Constraints

Evidence is safe metadata only. Never capture output, paths, PIDs, commands,
provider information, environment values, or credentials.

## Implementation Notes

Reuse the existing injected Popen seam and safe result projection. No service,
background daemon, retry, or persistence layer.

## Validation Steps

Run focused/affected tests, pycompile, validation, and diff check.

## Escalation Rules

Stop and record incident for any need to inspect child output or host secrets.
