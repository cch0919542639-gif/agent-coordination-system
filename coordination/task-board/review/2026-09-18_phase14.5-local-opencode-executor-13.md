# Task Packet

## Objective

Implement the separately reviewable L1 local OpenCode process boundary that
can be called only by a future, exact Phase H one-shot approval.

## Context

The operator selected local `opencode` as the L1 runtime. Read the accepted
L1 adapter/provisioner contract and Phase H protocol. This task prepares the
executor only; it is not a pilot launch.

## Constraints

L1 remains `best_effort`, not a sandbox. Network activation, credential
access, merge, push, destructive cleanup, Git worktree mutation, and runtime
execution remain prohibited during this task. Do not add a CLI, daemon,
persistence, fallback runtime, dependency, or provider integration.

## Implementation Notes

Use the standard library and an injected spawn boundary. Never use a shell.
Keep a single fixed executable mapping and a narrow allowlisted environment;
the public result must expose only safe IDs and terminal categories.

## Token And Resource Impact

Tests use fake spawns only. A future real call is limited to one approved run
and one process tree; withholding approval prevents the call.

## Validation Steps

Run focused executor tests, the affected Phase B.1--H suite,
`scripts/orchestrate.py validate`, and `git diff --check`.

## Escalation Rules

Stop and create an incident if any required OpenCode behavior needs network
activation, credential access, an unallowlisted executable/argument, an
absolute path in evidence, or a real test invocation.
