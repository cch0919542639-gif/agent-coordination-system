# Task Packet

## Objective

Implement the user's approved Phase H control model: approval is born at real
launch, progress is governed by a renewable supervisor lease, and each worker
uses only its assigned project worktree as context.

## Context

A fixed guessed completion time is unsuitable for variable agent work. The
supervisor must distinguish an alive child from missed worker reporting and
must terminate, record, and report a failed run rather than silently retry.

## Constraints

This is L1 `best_effort` coordination, not an OS sandbox. The child process
must not inherit arbitrary host configuration. Existing provider login remains
opaque to this system; it is neither discovered nor forwarded as a path/value.

## Implementation Notes

Reuse the existing exact validation, durable scheduler lease primitives, and
injected child seams. Prefer one shared validation path over a new service or
background daemon. A finite per-child hard ceiling remains a safety backstop,
not the task-duration estimate.

## Validation Steps

Run focused supervisor/executor/provision tests, affected Phase B.1--H tests,
`py_compile`, coordination validation, and diff check.

## Escalation Rules

Stop and record an incident if implementation requires a real launch, host
credential/config read, arbitrary environment inheritance, unrestricted
duration, retry/fallback, or a new background service.
