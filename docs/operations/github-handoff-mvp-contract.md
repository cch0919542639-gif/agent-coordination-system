## Queue and worker behavior

Git is transport: use a dedicated bare/local cache, plumbing or dedicated owned index, never stage/commit/reset the user's project worktree. Configured queue_ref holds dispatch/<dispatch_id>/assignment.json and task.md snapshots plus receipts/<dispatch_id>/claim.json and status.json. Use fixed origin, shell-free bounded Git calls, noninteractive auth, no token URLs, no force. Queue commit writes are fast-forward; bounded race retry must refetch and revalidate immutable objects. Do not silently rebase user branches.

Assignment v1 includes dispatch_id, project_id, task_id, owner, machine_id, base_revision, card_sha256, card_filename. Use exact canonical READY card metadata, validate bounded relative scopes and task ID, no traversal or arbitrary path/command from payload. dispatch_id deterministically binds all identities/card hash/base revision. Code_ref cached commit must match expected_revision. Task card may be uncommitted locally: queue publishes only its explicit snapshot, without committing project changes. Worker creates a NEW dedicated workspace from pinned code_revision, hydrates only its matching card snapshot, and refuses existing mismatched/dirty workspaces.

Cross-clone claim uniqueness uses immutable claim.json with random run_id: publish and verify this remote claim before execution, so competing receivers cannot both execute even if identity is misconfigured twice. Local SQLite unique dispatch/fingerprint and exclusive worker lock preserve dedupe across replay/restart. Same ID/different payload refuses. RUNNING after interruption is UNKNOWN/manual recovery, never blind relaunch. RECEIVED may execute later with the same locally persisted run_id and unchanged remote claim. Status writes must match claim run_id/card/peer, monotonic transitions; failed receipt publication preserves a local outbox and retries publication, not execution. No auto retry of a failed or unknown runner.

JobProcess is scripts/worker_process_guard.py: construct(...,cwd=workspace,capture_output=False), resume(), wait(timeout), wait_empty(), stop() only on owned Job when needed. Capture actual root exit plus stopped-tree proof; no transcript capture. Recheck remaining watch budget after receipt/outbox publication and immediately before owned Job resume/wait; an elapsed deadline cannot authorize a new runner. Cleanup must occur in finally. Unsupported/unknown containment refuses execution. Existing controlled OpenCode/Hermes launcher may be supplied as an explicitly approved local runner adapter later; tests use a harmless script marker, not provider/API calls.
