Agent 工作階段

手動啟動

使用 Agent 原生登入與提供者設定。OpenCode 工具命令會直接執行，不逐項詢問；設定於重新連線後生效。Hermes 新連線使用精簡工具：讀寫、修補及搜尋檔案、終端與程序管理；不載入其他工具或 MCP，背景程序不接受互動輸入。Hermes 偵測為危險的命令須逐次授權，其他命令可能直接執行；這不是作業系統沙箱。Hermes 請使用模型選單切換；來源核對僅涵蓋主模型的提供者與端點，未驗證帳號身分。原生自動標題或對話壓縮等輔助功能可能依設定將內容傳送給其他提供者，未經此核對。實際用量與資料政策由提供者決定。

多模型與 Agent 自動分工

設定 2 至 4 個工作者；第一個直接模型負責拆分和彙整。總任務及分工內容會傳給各供應商，其他模型結果的前 4000 字也會傳給第一個供應商彙整，可能產生費用。非 OpenRouter 供應商的零資料保留不由主控台驗證。

OpenCode 與支援的 Hermes 可執行工具與修改檔案；各自使用目前專案最新 Git 提交建立的工作目錄，不包含原工作目錄未提交的變更。工作目錄不是安全沙盒，Agent 可能存取帳號有權存取的其他檔案及憑證，Git 資料庫也由工作目錄共用。OpenCode 工具操作沿用直接執行設定；Hermes 危險操作須審批。主控台不會主動合併成果，但無法限制 Agent 的命令。

請手動輸入各供應商提供的模型 ID；OpenRouter 模型 ID 可先在下方直接模型的清單中查詢。
